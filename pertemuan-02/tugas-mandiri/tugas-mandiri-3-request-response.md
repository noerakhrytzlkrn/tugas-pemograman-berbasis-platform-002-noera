# Tugas Mandiri 3 - Memahami Request dan Response
## Pertanyaan dan Jawaban

### 1. Apa perbedaan antara request dan response?

**Jawaban:**
Request adalah permintaan yang dikirim oleh client kepada server untuk meminta data atau melakukan suatu tindakan. Sedangkan response adalah balasan yang diberikan oleh server kepada client setelah request tersebut diproses.
### 2. Apa fungsi query parameter pada request?

**Jawaban:**
Query parameter berfungsi untuk mengirimkan informasi tambahan kepada server melalui URL. Query parameter biasanya digunakan untuk menentukan data yang ingin dicari, difilter, atau diproses oleh server.
### 3. Apa fungsi header pada request?

**Jawaban:**
Header berfungsi untuk membawa informasi tambahan mengenai request yang dikirim dari client ke server. Informasi tersebut dapat berupa jenis data yang diterima, informasi client, autentikasi, dan informasi lain yang diperlukan oleh server untuk memproses request.
### 4. Apa arti status code 200 pada response?

**Jawaban:**
Status code 200 berarti request yang dikirim oleh client berhasil diterima, diproses, dan dijawab oleh server. Status ini menunjukkan bahwa proses request berjalan dengan baik atau berhasil (OK).
### 5. Apa perbedaan antara query parameter dan header?

**Jawaban:**
Query parameter adalah informasi tambahan yang dikirim melalui URL dan biasanya digunakan untuk menentukan atau memfilter data yang diminta. Sedangkan header adalah informasi tambahan mengenai request yang tidak ditampilkan sebagai bagian dari URL, seperti jenis data, informasi client, dan autentikasi.
